# Мобільний менеджер задач (Google Sheets + Calendar PWA)

Веб-додаток без збірки (HTML, CSS, Vanilla JS) для керування задачами з Google Таблиці та створення нагадувань у Google Календарі. Працює як PWA на iPhone (`Add to Home Screen`) та адаптується під 4-колонковий канбан на широких екранах.

## Структура таблиці

Назва аркуша в Google Таблиці має бути точно **`Задачі`**. Перший рядок містить заголовки, дані починаються з 2-го рядка:

| Стовпець | Поле | Значення |
|---|---|---|
| A | `Готово` | Чекбокс (`TRUE` / `FALSE`) |
| B | `Сфера` | `Крипта`, `Навчання`, `Життя` |
| C | `Задача` | Текст задачі |
| D | `Статус` | `Беклог`, `Цей тиждень`, `В роботі`, `Готово` |
| E | `Пріоритет` | `Високий`, `Середній`, `Низький` |
| F | `Дедлайн` | Дата `yyyy-MM-dd` |
| G | `Час` | Час `HH:mm` |
| H | `Нотатки` | Додатковий текст |
| I | `В Календарі` | Чекбокс (`TRUE` / `FALSE`) |

## 1. Налаштування бекенду в Google Apps Script

1. Відкрийте вашу Google Таблицю з аркушем `Задачі`.
2. У верхньому меню виберіть **Розширення -> Apps Script** (*Extensions -> Apps Script*).
3. Видаліть шаблонний код у файлі `Code.gs` і вставте вміст файлу [`backend/Code.gs`](./backend/Code.gs).
4. На початку коду замініть значення константи `SECRET_PIN` на власний секретний код:
   ```js
   const SECRET_PIN = 'ваш_надійний_код';
   ```
5. Перевірте часовий пояс скрипта: відкрийте **Налаштування проєкту** (іконка шестерні ліворуч) і переконайтеся, що часовий пояс збігається з вашим (наприклад, `GMT+02:00 Europe/Kyiv`).
6. У **правому верхньому куті** редактора Apps Script натисніть синю кнопку **Ввести в дію** (або **Розгорнути** / **Deploy**) → **Нове введення в дію** (*New deployment*):
   - Натисніть іконку шестерні біля **Виберіть тип** (*Select type*) → **Веб-додаток** (*Web app*).
   - Виконувати як (*Execute as*): **Я** (*Me*).
   - Хто має доступ (*Who has access*): **Усі** (*Anyone*).
7. Натисніть синю кнопку **Ввести в дію** (*Deploy*) унизу вікна і надайте дозволи на доступ до Google Таблиць та Google Календаря (під час першого попередження Google натисніть *Додатково / Advanced -> Перейти на сторінку ... (небезпечно) -> Дозволити / Allow*).
8. Скопіюйте отриманий **URL веб-додатку** вигляду `https://script.google.com/macros/s/.../exec`.

> При подальших змінах у `Code.gs` відкривайте **Ввести в дію -> Керувати введеннями в дію -> Редагувати (іконка олівця) -> Версія: Нова версія -> Ввести в дію**, щоб URL веб-додатку залишався тим самим.

## 2. Публікація фронтенду на GitHub Pages

1. Створіть новий репозиторій на GitHub і завантажте в його корінь файли цього проєкту (`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, папки `icons/` та `backend/`).
2. У репозиторії відкрийте **Settings -> Pages**.
3. У розділі **Build and deployment**:
   - **Source**: виберіть `Deploy from a branch`.
   - **Branch**: виберіть `main` (або `master`), папка `/ (root)`, і натисніть **Save**.
4. За 1–2 хвилини додаток стане доступним за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`. Усі шляхи у проєкті відносні (`./`), тому підпапка репозиторію працює без додаткових налаштувань.

## 3. Підключення та встановлення на iPhone

1. Відкрийте адресу вашого GitHub Pages у браузері **Safari** на iPhone.
2. У вікні «Підключення таблиці», яке відкриється автоматично, вставте скопійований **Web App URL** та ваш **PIN**, після чого натисніть **Зберегти і підключити**.
3. Щоб встановити додаток на головний екран без адресного рядка Safari:
   - Натисніть кнопку **Поділитися** (квадрат зі стрілкою вгору внизу екрана).
   - Прокрутіть список униз і виберіть **На початковий екран** (*Add to Home Screen*).
   - Натисніть **Додати** (*Add*).
4. Відкривайте іконку **Задачі** з домашнього екрана: останній стан списку миттєво завантажується з локального кешу `localStorage`, а свіжі дані фоново підтягуються з Google Таблиці.

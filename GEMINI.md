# GEMINI.md — Архітектурна конституція: Tasks PWA v3 PRO (Trello × Cryptan Cockpit)

Цей документ визначає архітектурні правила, схему даних та стандарти розробки мобільного й десктопного менеджера задач **Tasks PWA v3 PRO**.

## 1. Контекст системи та філософія
- **Zero-Build / Zero-CDN / Offline-First**: чистий семантичний HTML5, модульний CSS3 та нативні ES6-модулі (`import`/`export`), без React, npm, збирачів чи зовнішніх CDN. Миттєвий старт на iPhone Safari (`Add to Home Screen`) і ПК з GitHub Pages.
- **Двостороння сумісність із Google Таблицею**: бекенд Google Apps Script (`backend/Code.gs` + `backend/Journal.gs`) працює напряму з аркушем `Задачі` (стовпці `A–I`), не ламаючи формули аркуша `Канбан і Дашборд` (`$C$2:$C$100`, `TODAY()`), переносить закриті задачі в аркуш `Архів` та зберігає щоденник і звички в окремому аркуші `Щоденник` (стовпці `A–G`).
- **Anti-Monolith Rule**: жоден модуль у `/js` не перевищує **500 рядків коду** (`<= 500 LOC`).

## 2. Безпека та цілісність даних
1. **POST-only API**: PIN/пароль ніколи не передається у query-параметрах URL; усі операції (`list`, `create`, `update`, `delete`, `syncCalendar`, `archiveDone`, `saveJournalDay`, `saveJournalMeta`) йдуть через `POST`.
2. **Script Properties + Rate-Limit**: пароль зберігається у `PropertiesService.getScriptProperties()` (не затирається при оновленні коду), а `CacheService` блокує перебір після 10 невдалих спроб на 5 хвилин.
3. **Захист від ін’єкції формул та XSS**: значення з префіксами `=`, `+`, `-`, `@` екрануються апострофом перед записом у Sheets; увесь динамічний текст у DOM проходить через `escapeHtml()`, а посилання — через `safeUrl()` / `safeApiUrl()`.
4. **Конкурентний захист**: `LockService.getScriptLock()` на бекенді + `expectedTask` звірка рядка + персистентна клієнтська черга мутацій (`localStorage`) з підтримкою офлайн-режиму.
5. **Zero-Plaintext у репозиторії**: приватний `Web App URL`, `sheetUrl` та `SECRET_PIN` зберігаються виключно в `localStorage` пристрою користувача (з кнопкою повного очищення в 2 кліки).

## 3. Схема даних (`Задачі`, стовпці A–I)
- **A (1)** `Готово` — boolean чекбокс (синхронізований зі статусом `Готово`).
- **B (2)** `Сфера` — `Крипта` | `Навчання` | `Життя`.
- **C (3)** `Задача` — назва задачі.
- **D (4)** `Статус` — `Беклог` | `Цей тиждень` | `В роботі` | `Готово` (порядок воронки Trello зліва направо).
- **E (5)** `Пріоритет` — `Високий` | `Середній` | `Низький`.
- **F (6)** `Дедлайн` — справжня дата Sheets (`yyyy-mm-dd`), у JSON передається як `yyyy-MM-dd`.
- **G (7)** `Час` — текст `@` у форматі `HH:mm`.
- **H (8)** `Нотатки` — чистий текст + людиночитабельна розмітка чеклістів (`- [ ]` / `- [x]`), тегів (`#bybit`, `#342`), закріплення (`[pin]`) та повторів (`[repeat:daily|weekly:...|monthly:...|every_n:...]`).
- **I (9)** `В Календарі` — boolean чекбокс синхронізації з Google Calendar.

## 4. Аркуш `Щоденник` (стовпці A–G)
- Рядок `2` (`A2 = "__CONFIG__"`): зберігає список звичок (`D2` JSON) і фокуси місяця `{ "YYYY-MM": "..." }` (`G2` JSON).
- Рядки `3+`: щоденні записи (`Дата yyyy-mm-dd`, `Оцінка 1–10`, `Фокус дня`, `Звички` через кому, `Що вдалося`, `Що заважало`).

```text
d:\Google PWA\
├── GEMINI.md             # Архітектурна конституція проєкту
├── ROADMAP.md            # Карта реалізованих фіч та беклогу
├── README.md             # Інструкція розгортання Apps Script + GitHub Pages + iPhone
├── index.html            # DOM-каркас + суворий CSP
├── styles.css            # Базові токени Pilot Cockpit, шапка, картки, модалки

├── manifest.json         # PWA-маніфест
├── sw.js                 # Service Worker v6 (network-first для HTML, stale-while-revalidate для статики)
├── backend/
│   ├── Code.gs           # Google Apps Script API v3 PRO (роутер + задачі/календар/архів)
│   └── Journal.gs        # Модуль аркуша «Щоденник» (фокус, звички, оцінка 1–10)
└── js/
    ├── utils.js          # Словники, escapeHtml/safeUrl, дати, живий відлік <24h, сортування
    ├── notes-meta.js     # Парсер і серіалізатор чеклістів, #тегів, [pin] та [repeat] у Нотатках
    ├── fx.js             # Акордовий Web Audio SoundEngine + тактильний 3D-нахил (FX 3D / Eco)
    ├── timers-dock.js    # Плаваючий док Фокус-таймерів (5–60 хв) + режим «Поверх вікон» (PiP)
    ├── api.js            # POST-клієнт, персистентна офлайн-черга та звірка рядків
    ├── day-view.js       # Вкладка «День», плашка Фокусу, трекер звичок + streak і статистика
    ├── views.js          # Режими «Календар» (місячна сітка) та «Дашборд прогресу %» + SVG-графік
    ├── ui.js             # Рендер Trello-дошки, інлайн +Додати картку, чеклістів та тостів
    ├── modals.js         # Контролер модалок задач, чеклістів, повторів і налаштувань
    └── app.js            # Головний контролер стану, подій, Drag & Drop і хоткеїв
```
